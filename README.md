# Jardín Botánico Lego - Entorno 3D

> **Experiencia inmersiva en entorno 3D estilo Lego del Jardín Botánico de Bogotá José Celestino Mutis**

---

## Descripción General

**Jardín Botánico Lego** es un entorno virtual 3D interactivo desarrollado en **Unity 2022.3.57f1** que permite a visitantes explorar digitalmente el **Jardín Botánico de Bogotá José Celestino Mutis**. El proyecto modela algunas zonas del jardín físico con un estilo visual Lego distintivo, proporcionando una experiencia de navegación inmersiva que complementa y enriquece la visita física al espacio.

### Propósito

Este entorno virtual sirve como herramienta educativa y de pre-visualización que permite a visitantes:

- Familiarizarse con la disposición y estructura del jardín antes de visitarlo físicamente
- Complementar la experiencia presencial con información inmersiva
- Generar interés en la biodiversidad y ecología del jardín botánico

---

## Características Principales

- **Entorno 3D Inmersivo**: Reconstrucción virtual del Jardín Botánico José Celestino Mutis
- **Estilo Visual Lego**: Diseño distintivo y amigable basado en estética Lego

## Instalación y Ejecución

### Requisitos del Sistema

- **Unity 2022.3.57f1** instalado
- Capacidades gráficas básicas de 3D
- Espacio en disco: Aproximadamente 500 MB - 1 GB (depende de los assets)
- Memoria RAM: Mínimo 4 GB

### Pasos de Instalación

1. Clonar o descargar el repositorio
2. Abrir el proyecto en Unity 2022.3.57f1
3. Cargar la escena principal desde la carpeta del proyecto
4. Ejecutar el proyecto en el editor o hacer build para distribución

### Construcción Ejecutable

Para crear un build distributable:

1. Ir a File → Build Settings
2. Seleccionar la plataforma objetivo (Windows PC, macOS, WebGL, etc.)
3. Añadir las escenas necesarias a la lista de Build
4. Configurar las opciones de calidad y resolución
5. Ejecutar Build

## Relación con el Jardín Botánico de Bogotá

Este proyecto es una representación virtual del **Jardín Botánico de Bogotá José Celestino Mutis**, uno de los espacios más importantes para la educación ambiental y la conservación de biodiversidad en Colombia.

El entorno Lego no pretende ser una réplica exacta, sino una interpretación inmersiva y educativa que:

- Captura la esencia y distribución del jardín físico
- Permite familiarización previa a una visita presencial
- Genera interés en la biodiversidad local
- Complementa programas educativos del jardín

## Glosario de Términos

- **Entorno 3D**: Espacio virtual tridimensional interactivo
- **Assets**: Recursos (modelos, texturas, sonidos) utilizados en el proyecto
- **Build**: Compilación del proyecto Unity en ejecutable
- **Escena**: Nivel o área específica dentro de un proyecto Unity
- **Lego**: Estilo visual basado en bloques modulares de construcción
- **Navegación**: Sistema de movimiento y control del usuario en el entorno
